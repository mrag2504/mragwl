# MrAG Channel Website 🚀

Wobbly Life + Space Update themed website for **MrAG** YouTube channel.

## Features
- Beautiful space-themed design with animated stars
- Videos section
- Updates section (each post opens in a new tab)
- Fully responsive (mobile + desktop)
- English only
- Only the channel owner can add new posts (no public posting form)

## How to use
1. Open `index.html` in any browser
2. Click on any update card → it opens the full post in a **new tab**
3. To add a new post later: create a new HTML file (copy `post-space-update.html`) and add a new card link in `index.html`

## Files
- `index.html` → main page
- `post-space-update.html` → first post (Space Update)
- `style.css` → all styling
- `script.js` → stars + mobile menu
